# speedtest

Скрипт замеряет скорость интернета: последовательно скачивает один и тот же файл
несколько раз и печатает среднее время запроса, объём скачанных данных и скорость в МБ/с.

Тестовое задание для Ad Robot (Eto Legko).

## Требования

Python 3.8+. Внешних зависимостей нет — только стандартная библиотека.

## Запуск

```bash
python speedtest.py <URL>
```

По умолчанию делается 10 запросов с таймаутом 30 секунд.

Параметры:

```bash
python speedtest.py <URL> --requests 20 --timeout 60
python speedtest.py <URL> -n 5 -t 15
```

| Флаг | Значение | По умолчанию |
|---|---|---|
| `-n`, `--requests` | сколько раз скачать файл | 10 |
| `-t`, `--timeout` | таймаут одного запроса, секунды | 30 |

## Пример

```
$ python speedtest.py https://example.com/heavy.jpg -n 4

Замеряю скорость на https://example.com/heavy.jpg (4 запросов)

[1/4] 0.412 c, 3.00 МБ, 7.28 МБ/с
[2/4] 0.395 c, 3.00 МБ, 7.59 МБ/с
[3/4] 0.388 c, 3.00 МБ, 7.73 МБ/с
[4/4] 0.401 c, 3.00 МБ, 7.48 МБ/с

--- Итог ---
Успешных запросов:     4 из 4
Среднее время запроса: 0.399 с
Скачано всего:         12.00 МБ (12582912 байт)
Средняя скорость:      7.52 МБ/с
```

## Решения по реализации

**Скорость считается как общий объём делить на общее время**, а не как среднее
арифметическое скоростей отдельных запросов. При усреднении скоростей быстрый
запрос весил бы столько же, сколько медленный, и итог оказался бы завышен.

**Тело ответа читается потоком по 64 КБ** и до конца. Если не дочитать, часть
данных осталась бы в буфере и замер был бы нечестным. Потоковое чтение заодно
не держит файл целиком в памяти.

**Время измеряется `time.perf_counter()`**, а не `time.time()`: монотонные часы
не прыгают при коррекции системного времени.

**Ошибки отдельных запросов не роняют замер.** Недоступный ответ логируется в
stderr, остальные запросы продолжаются, а в итоге видно, сколько из скольких
прошло. Если не прошёл ни один — выход с кодом 1.

**Запросы идут последовательно**, как в задании: параллельные забеги мерили бы
пропускную способность канала, а не время отдельного запроса.
